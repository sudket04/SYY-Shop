## เปิดใช้งาน / ข้อมูลย้อนหลัง

บิลที่สร้างใหม่ใช้ `SI-YYYYMMDD-0001` ตามวัน Bangkok โดย counter/reservation commit พร้อมการตัดสต๊อก และ Dashboard Sales Invoices คลิกเลขเปิดรายละเอียดได้สำหรับ staff/admin รักษา Doc_No และ idempotency key เดิม การออกบิลหนึ่งครั้งเพิ่ม counter lookup 1 ครั้งกับ metadata writes 2 เอกสาร; การเปิดรายละเอียดอ่านเฉพาะบิลและใช้ Shared cache เมื่อยังสด

**ยังไม่รันเติม Bill_No/Stock_Issue_Bill_No ย้อนหลัง** ประวัติเก่าจึงยังแสดงเลขเดิมจนกว่าจะตรวจและอนุมัติ mapping/hash ตาม [แผนย้อนหลัง](SALES-BILL-NUMBERS-2026-10-19.md) หากมีบิลใหม่ใช้เลขของวันนั้นไปแล้ว การเติมบิลเก่าจะต่อจาก counter ปัจจุบันและไม่เปลี่ยนเลขที่ออกแล้ว ไม่รับรองลำดับเลขตรงเวลาเรียงทั้งวันย้อนหลังโดยการ renumber อัตโนมัติ
