# เลขรายการและการแก้ไขสินค้าทั้งบิล — 29 ตุลาคม 2569

ผู้ใช้ให้ปิดงานโหลดหน้าก่อน แล้วปรับประวัติเข้า-ออกสินค้าให้คลิกเลขรายการ เปิดรายการสินค้าทั้งบิล เพิ่ม/แก้/ลบสินค้า และแยกปุ่มบันทึกการแก้ไขกับยกเลิกบิล พร้อมอนุมัติ Deploy ใช้งานจริง

## สิ่งที่เปลี่ยน

- เลขรายการใช้ Bill_No สำหรับแสดงผล และ Doc_No เดิมสำหรับอ่านรายละเอียดที่ตรงกับบิล รวมรายการที่ไม่ได้อยู่ในหน้าประวัติปัจจุบัน เส้นทางนี้มีอยู่แล้วและคงไว้
- เปิดแก้ไขแล้วแสดงสินค้าทุกแถวทันที พร้อมชื่อที่บันทึกในบิล แก้รหัส/จำนวน/ราคาหรือลบเฉพาะแถวได้ เพิ่มสินค้าโดยค้นจาก catalog ที่โหลดแล้ว แสดงผลค้นไม่เกิน20ปุ่ม ไม่อ่าน DB ต่อการพิมพ์ และรวมจำนวนเมื่อเพิ่มรหัสเดิม
- ปุ่ม **บันทึกการแก้ไข** แยกจาก **ยกเลิกบิล** และ **ยืนยันยกเลิกบิล** ชัดเจน ไม่มีการยกเลิกจากปุ่มบันทึก การลบทุกรายการในโหมดแก้ไขถูกปฏิเสธและแนะนำให้ใช้ยกเลิกบิล
- รองรับแก้เฉพาะหมายเหตุ/อ้างอิงโดยไม่เปลี่ยนสินค้า ทั้งการแก้และยกเลิกต้องระบุเหตุผลและตรวจ preview ปัจจุบันก่อนยืนยัน
- รักษา revision, preview token, request ID และกลไก atomic correction เดิมของ Version101 เมื่อไม่ทราบผลจะล็อกฟอร์ม เก็บคำขอและตรวจคำขอเดิมหลัง reload ไม่มีการส่งซ้ำอัตโนมัติ

## ขอบเขตข้อมูลและสิทธิ์

ใช้สิทธิ์ Admin และบิลตัดสต๊อก OUT ที่ยัง active เดิม สูงสุด200รายการ/บิล บิลรับเข้า, reversal, ยกเลิก/แทนที่แล้ว และรายละเอียดที่โหลดไม่ครบ เปิดดูได้แต่ไม่เปิดแก้ผ่าน workflow นี้ การขยายไปบิลรับเข้าต้องตรวจการคืนยอดและสถานะใบสั่งซื้อเพิ่มเติมตามคำถามขอบเขตที่ส่งให้ผู้ใช้

การแก้รายการใช้บิลทดแทนและรายการย้อนผลพร้อม audit เดิม ไม่ลบประวัติเดิม ไม่เปลี่ยน schema/Rules/IAM/สิทธิ์ผู้ใช้ การ Deploy ไม่รัน correction, historical backfill, Backup หรือการเขียน DB ใด ๆ
