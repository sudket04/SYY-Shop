## Checks / smoke / Firestore impact

- ก่อน Deploy: **275 unit tests**, **131 browser regression groups + 9 backend-integrated browser groups**, syntax/manifest **70 scripts**, read-model และ diff check ผ่านในเครื่อง บริการและข้อมูลทดสอบเป็น fixtures
- หลัง Deploy: เปิด URLเดิมโดยไม่มี token พบฟอร์ม Login ชื่อผู้ใช้/รหัสผ่าน/ปุ่มเข้าสู่ระบบ ไม่พบ ReferenceErrorหรือ browser error logs (`0`)
- ไม่มี authenticated shop sessionที่พร้อม จึง **ไม่ได้ Login หรือทดสอบเมนู/สร้างบิล/แก้บิลจริง** ไม่ถือว่า smokeผ่านเท่ากับ authenticated UAT
- ตรวจ Triggerแบบอ่านอย่างเดียว: **1 time-driven trigger `dailyBackupJob_`** UIระบุ Version101, เรียกใช้ล่าสุด **28ต.ค.22:02:30**, historical error rate **85.71%** ไม่เพิ่ม/แก้/ลบTriggerและไม่กดรันBackup
- **ไม่มีการเขียน/แก้/ลบเอกสารFirestoreจริงโดย agent** ไม่ตัด/รับสต๊อก ไม่เปลี่ยนบิลเก่า ไม่ส่งเอกสาร ไม่ Restore และไม่ backfill
- ผลลด returned documents/JSONจากfixturesยังไม่ใช่ billed Reads/Writesหรือเวลาจริงหลัง Deploy โดยเฉพาะเป้าทุกหน้า **≤10วินาทียังไม่ผ่านการวัดบนGoogle**

การ Deployไม่ใช่ migration ของ business data ฟิลด์ correction/counterจะเกิดตามธุรกรรมที่ผู้มีสิทธิ์สั่งใช้งานภายหลัง; read-only year getterไม่สร้าง metadata เอง ส่วนการบันทึก Quotationที่ metadataหาย/ว่างจะ initializeปีผ่าน write pathที่มีอยู่แล้ว ไม่มี collection/indexใหม่
