## สิ่งที่เปิดใช้

- early bootstrap และ ready/ACK ของ iframe พร้อม origin/channel/window validation และ bounded retry ของข้อความที่ไม่เรียก business API
- แสดง Login/หน้าข้อมูลโดยไม่รอ fonts, SweetAlert, PDF, Excel หรือ QR จาก CDN; เครื่องมือโหลดเมื่อใช้และมี error recovery
- แยก auth infrastructure unavailable จาก session หมดอายุ และแยก lock busy จาก read-rate exhaustion โดยยัง fail closed เมื่อตรวจสิทธิ์ไม่ได้
- คิวอ่าน foreground มาก่อนรูป ข้ามคำขอสินค้าที่รอคิวและถูกแทนที่แล้ว ทิ้ง late callback ของคำขอหมดเวลา; คง write/CAS/idempotency/replay เดิม
- กล่องยืนยันสำรองรองรับ keyboard/focus ใน modal และยกเลิกอย่างปลอดภัยเมื่อ session หมดอายุ ไม่ยืนยันหรือบันทึกเองเมื่อ CDN ล่ม
- diagnostics ใน memory/console โดยไม่ส่ง telemetry หรือเพิ่ม Firestore write

## Firestore และขอบเขตข้อมูล

**ไม่มีการเขียน แก้ไข หรือลบ Production DB โดยผู้ดำเนินการรอบนี้** ไม่กดบันทึกสินค้า/ตัดสต๊อก/แก้บิล/ยกเลิกบิล ไม่ส่งLogin ไม่รันBackup/Restore และไม่ทำmigration/backfill
