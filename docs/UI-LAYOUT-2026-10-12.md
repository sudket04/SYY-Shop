# SYY-Shop — ปรับ UI ตามภาพ วันที่ 12 ตุลาคม 2569

## 1. ผลลัพธ์
แก้ข้อความ include ที่โผล่ทุกหน้า, dropdown เกินในกล่องยืนยัน, สีปุ่มเพิ่มสินค้าที่ไม่สม่ำเสมอ, การเลื่อนเลือกสินค้าด้วยคีย์บอร์ด และสัดส่วนหน้าจอ desktop/mobile รวมส่วนกลางที่หน้าอื่นใช้ร่วมกัน

## 2. Root Cause
UiSystem.html มี printing scriptlet เพื่อ include UiEnhancements ซ้อนอยู่ แต่ include_ คืน raw HTML ไม่ประเมิน template ซ้ำ จึงแสดง scriptlet เป็นข้อความและกินพื้นที่ของ flex layout ใน shell ด้วย ไม่เปิดใช้งาน UiEnhancements รุ่นเก่าเพื่อแก้ปัญหานี้ เพราะมี select implementation ซ้ำและ gallery workers ที่ไม่ใช่เส้นทางปัจจุบัน

Shared.html แปลงทุก select รวม select ที่ SweetAlert สร้างและซ่อนไว้เป็น custom dropdown ทำให้ wrapper แสดง "เลือก..." ใน confirmation ที่ไม่มี input ใช้งาน การแก้ให้ SweetAlert ดูแล input ของตัวเองครอบคลุมกล่องยืนยันทุกหน้าและไม่ปิด input จริงของ SweetAlert

Stock Issue เลือกแถวแรกด้วย selIdx=0 และ CSS เปลี่ยนสีปุ่มในแถว .sel เป็นเข้ม จึงเกิดสีต่างกัน การใช้ border 2px เปลี่ยนความสูงแถว และ moveSel เคย render ทั้งรายการใหม่ทุกครั้งพร้อมใช้ offsetTop ที่ไม่ผูกกับพิกัด viewport ของกรอบ scroll

หน้า .page จำกัด 1400px และตาราง <=5 คอลัมน์ใช้ width:auto ทำให้ข้อมูลแคบเมื่อพื้นที่มาก Users จำกัด 1100px การตรวจเพิ่มเติมที่ 320px พบ toolbar สินค้าล้นเพราะช่องค้นหามี minimum width และกลุ่ม count/columns/page-size ไม่ wrap

## 3. ผลกระทบต่อ Module
Styles/Shared/UiSystem ใช้ร่วมกันทั้ง shell และหน้าข้อมูลหลัก/เอกสาร/สต๊อก ไม่เปลี่ยน business payload, API registry, authentication, role, stock validation, draft confirmation หรือ write retry behavior กรอบตารางกว้างยังเลื่อนแนวนอนภายในกรอบตามเดิม

## 4. วิธีแก้
ลบ nested include ที่ไม่ถูกประเมินและไม่ได้ทำงานจริง ใช้ระบบ select และ gallery ปัจจุบันต่อ เพิ่มข้อยกเว้น SweetAlert และ native listbox ใน select enhancer ขยาย .page/ตาราง compact/Users ให้เต็มพื้นที่ เพิ่มระยะ 8px ใต้ sticky page header และ 6px ใต้หัวตาราง เพิ่มกรอบ/scroll padding ให้ผลค้นหาสินค้าและความสูงสัมพันธ์กับ viewport

คงสีปุ่มเพิ่มสินค้าเหมือนกัน ใช้สีพื้นและเส้นข้างเพื่อบอกแถวที่เลือกโดยไม่เปลี่ยนความสูง ลูกศรเปลี่ยนเฉพาะ class ของสองแถวและเลื่อนภายในกรอบด้วย bounding rectangles ไม่สร้าง DOM ทั้งรายการใหม่ ปรับการ wrap ของ stock cards และ product toolbar บนมือถือ

## 5. ความเสี่ยงและขอบเขต
CSS ส่วนกลางมีผลหลายหน้า จึงตรวจ browser ทุก route และ layout หลายความกว้าง ไม่เปลี่ยนโครงสร้างระบบหรือข้อมูล Production ต้องอัปเดตไฟล์รุ่นเดียวกันใน Apps Script และทดสอบ deployment จริงอีกครั้ง SweetAlert regression ใช้โครงสร้าง hidden/native select จำลองกับ enhancer จริง ไม่อ้างว่าได้ทดสอบ CDN library บน Production

## 6. Files Changed
Production 6 ไฟล์: UiSystem.html, Shared.html, Styles.html, StockIssue.html, Master_Products.html, Manage_Users.html เพิ่ม regressions ใน tests/browser.cjs และรายงานนี้ ไม่รวม untracked audit เดิมหรือ generated artifacts

## 7. การทดสอบ
npm test 113/113 และ syntax/manifest 68 scripts ผ่าน ตรวจ browser ทั้ง 15 routes เพื่อยืนยันไม่มี include scriptlet ในข้อความที่แสดง เพิ่มกรณี hidden SweetAlert select, native input ที่ตั้งใจแสดง, สีปุ่ม, 80-row keyboard navigation/DOM identity/scroll/no new RPC, compact width/sticky header และ 12 หน้า desktop 1920px/mobile 320px ตรวจภาพ stock desktop/390/320 และ brands หลังเลื่อนหัวตาราง รวม regression เดิมด้าน modal focus, searchable select, dirty draft, frame handoff, documents/print/mobile และ backend security/integrity

Browser regression ผ่าน 63/63 กลุ่ม ผลบันทึกใน test-results/browser-result.json ตรวจภาพ Stock desktop/390/320 และ Brands desktop หลัง scroll แล้ว ตารางแสดงชื่อ/รหัส/ปุ่มจัดการครบและไม่มีข้อความ include

## 8. Firestore Impact
เพิ่ม reads/writes/deletes 0 ไม่มี schema/index/rules/IAM/สิทธิ์เปลี่ยน การเลื่อนด้วยลูกศรไม่เพิ่ม RPC เช่นเดิม แต่ลดการสร้าง DOM ซ้ำ ไม่มีการวัด Production billing หรืออ้างเปอร์เซ็นต์ประหยัดใหม่

## 9. Commit และ Deployment
Commit/Push main ตามคำสั่งถาวร SHA คือ commit ที่เพิ่มรายงานนี้ ไม่มี Apps Script sync/deploy หรือ Production service calls สร้างแพ็กเกจ Source พร้อมตรวจ checksum ด้วยเครื่องมือ release เดิมเพื่อส่งมอบไฟล์รุ่นเดียวกันโดยไม่รวม credentials

## 10. คงเหลือ
นำ Source ที่แก้ไป Apps Script และทดสอบหน้า login/navigation, SweetAlert จริง, scroll, keyboard และขนาดหน้าจอที่ 100% ผ่าน Test deployments ก่อน Production rollout ที่ได้รับอนุมัติ เก็บเวอร์ชันเดิมสำหรับ rollback ไม่เปลี่ยน access/execution settings ของ deployment
