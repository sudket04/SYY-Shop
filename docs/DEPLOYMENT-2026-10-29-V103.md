## Firestore impact

- แพตช์ audit เพิ่มการ render/validate ใน Browser ไม่เพิ่ม DB writes หรือ query ใหม่ การกด retry เมื่อ metadata อยู่ใน cache ไม่เรียก RPC เพิ่ม
- งาน prefetch รูปย้ายการอ่านล่วงหน้ามาที่หน้าปัจจุบันไม่เกิน100รายการ อาจเพิ่ม Reads ครั้งแรกเพื่อแลกกับเปิดรายละเอียดเร็วขึ้น คง cache สูงสุด300รายการ/2นาทีและ generation/account isolation
- Fixture150สินค้าที่มีเอกสารรูปทุกสินค้า: initial101 product results รวมlookahead +100 image results ใน1batch; เรียก batch ซ้ำเมื่อ cache อุ่นเพิ่ม0 image document results
- ประวัติใช้ bounded COUNT_UP_TO + batchIN ณ readTime เดียวกัน เติมเฉพาะบิลที่ candidate ไม่ครบ ไม่ทำ detail query ต่อแถวหรือเพิ่ม whole-collection scan ใน Browser
- ไม่เพิ่ม polling/telemetry write สำหรับ skeleton หรือการพิมพ์แก้จำนวน
- ตัวเลข fixture ไม่ใช่ billable usage จริง ไม่รวม auth/missing-document/index billing และไม่มีหลักฐานรับรองเปอร์เซ็นต์ Reads ลดทั้ง Production หรือทุกหน้าต่ำกว่า10วินาที
